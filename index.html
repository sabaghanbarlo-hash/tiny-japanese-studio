Tiny Japanese Studio

Upload a short anime clip (up to 3 minutes). Get back a finished lesson video: clip with subtitles, vocabulary, grammar and a quiz.

One-time setup (your private key)
  1. Open GitHub: new fine-grained token.
  2. Name it studio. Repository access: Only select repositories then tiny-japanese-lessons.
  3. Repository permissions: set Contents, Actions to Read and write. (Metadata read is automatic.)
  4. Generate, copy the token, paste it below. It stays only in this browser.
